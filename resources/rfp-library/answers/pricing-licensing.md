# Pricing & licensing

Source: validated RFP submission, 2026-07-30. Trust: `validated`.

## Plan gating — check this before ANY capability answer
A feature answer without its plan tier is half an answer. Confirmed
plan-gated as of 2026-07-30:

| Capability | Gate |
|---|---|
| Releases (coordinated multi-story publish) | Premium+ |
| Custom Workflows (custom stages, per-stage roles) | Premium+ (default draft→review→ready-to-publish is on all plans) |
| Custom roles / fine-grained permissions | Premium+ (Admin+Editor on all plans) |
| Native A/B Testing | Premium + Elite, no extra cost |
| First-party PIM plugin (see integrations.md) | Premium + Elite |
| Extended Activity Log | Enterprise |
| SSO | Enterprise **add-on** (not bundled) |
| Uptime SLA | 97% Self-Service / 99.9% Premium / 99.99% Elite |
| Designated Solution Architect | Elite |

## Licensing breakdown structure (what to itemise)
- Annual platform licensing — plan tier, included seats, locales, spaces,
  API call allowance, storage.
- SSO add-on (Enterprise).
- Support tier (tied to Premium vs Elite edition choice).
- Optional professional services (Designated Solution Architect on Elite).

Separate clearly into **platform (us)** / **implementation services
(partner, companion proposal)** / **third-party estimated costs**
(front-end hosting; external TMS if used; advanced personalisation tooling
if used). Vendors are usually asked for 3-year TCO — year 1 model plus
recurring years 2–3.

## Framing note
When procurement asks for financial-stability statements or insurance
details, "we'll cover this during the negotiation stage as the information
is confidential" is an acceptable, validated answer — it is not a gap.
